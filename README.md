# Dzine Wala — Portfolio Website

A modern and responsive portfolio website for **Dzine Wala**, designed to showcase creative work, highlight services, and establish a strong digital presence.

## ✨ Features

- Modern and visually appealing UI
- Responsive design for desktop, tablet, and mobile
- Portfolio and project showcase
- Services and brand presentation
- Smooth navigation and interactive elements
- Clean and maintainable code structure

## 🛠️ Tech Stack

- **Frontend:** React.js
- **Styling:** CSS / Tailwind CSS
- **Build Tool:** Vite
- **Language:** JavaScript

## 🚀 Getting Started

### Prerequisites

Make sure you have [Node.js](https://nodejs.org/) and npm installed.

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/juniorpawar/dzine_wala.git
   ```

2. Navigate to the project directory:

   ```bash
   cd dzine_wala
   ```

3. Open on live server or open the index.html in browser.
